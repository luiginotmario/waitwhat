# waitwhat? brand

Shared by the website and the Mac widget. **The structure is Apple; the pencil is the accent.**

| File | What it is |
| --- | --- |
| `tokens.css` | Design tokens as CSS custom properties (`--ww-*`): paper, graphite, 3b1b accents, materials, motion, radii. Light, blackboard dark, increased contrast and reduced transparency are all handled here. |
| `wordmark.svg` | The hand-lettered “waitwhat?” wordmark: single-stroke paths with the pencil filter baked in. Adapts to dark mode on its own. |
| `pencil-filter.svg` | The two graphite filters (`#ww-pencil`, `#ww-pencil-fine`). Inline the `<defs>` once per document. |

The wordmark paths and the draw-on timing are generated by `waitwhat-web/scripts/wordmark.mjs`, which writes `wordmark.svg` here and the web component's data. Edit the strokes there, not by hand. The web app copies `tokens.css` with `node scripts/sync-brand.mjs`.

## Rules

### Structure (Apple)
- **Type:** the system font (`--ww-font-ui`, SF Pro via `system-ui`) for every word of UI. Large text gets negative tracking (about `-0.02em` to `-0.03em`) and tight leading; body text sits near `0` tracking with a 1.45–1.5 line height.
- **Space:** generous. One idea per screen. The homepage is the wordmark, one input and a button.
- **Press:** everything pressable scales to `0.97` on `:active` (`--ww-dur-press`, `--ww-ease-out`). Hover only tints, and only behind `@media (hover: hover) and (pointer: fine)`.
- **Materials:** floating chrome (player controls, menus, modals) uses `backdrop-filter: var(--ww-material-blur)` over `--ww-material*` with a hairline `--ww-material-edge`. Chrome over video always uses `--ww-material-dark`.
- **Motion:** UI transitions stay under 300 ms, use `--ww-ease-out` for enter/exit, and animate only `transform` and `opacity`. Modals and sheets use `--ww-spring` (a critically damped spring baked into `linear()`), and they exit faster than they enter.
- **Accessibility:** honour `prefers-reduced-motion` (no movement, keep the fades), `prefers-reduced-transparency` (the tokens make materials solid) and `prefers-contrast: more` (the tokens darken secondary text and strokes).

### Accent (pencil)
- **Graphite strokes** (`#ww-pencil`) are for decoration and progress only: the input outline, underlines, construction lines, compass arcs, measurement annotations, storyboard frames. Never for text, icons or controls.
- **Graph paper** (`--ww-grid-*`) sits behind everything and fades toward the centre so content is always on clean paper. Ruler ticks run along the top and left edges (top only on phones).
- **Hand lettering:** “Architects Daughter” (`--ww-font-hand`) is only for the wordmark's surroundings and tiny annotations (11–15 px). Never for body text, labels or buttons.
- **Draw-on** happens in exactly two places: the wordmark on the first load of a session, and the generation progress drawing. Nothing else draws itself.

### Colour
- Light mode is graphite on paper (`--ww-paper`, `--ww-ink`, `--ww-graphite-1…5`). Dark mode is chalk on a blackboard.
- The 3b1b accents are blue `#58C4DD`, yellow `#FFFF00`, green `#83C167` and red `#FC6255`. On paper, use the `*-ink` variants for strokes and text, because the raw colours fail contrast. Use the raw `--ww-video-*` colours only on top of video frames.
- The question mark in the wordmark is the one permanent accent (blue).

### Don't
- Don't put the hand font in UI copy.
- Don't use a cartoon or marker look: strokes are thin, grey and grainy, like a real HB pencil.
- Don't animate hover states or anything that happens more than a few times a minute.
